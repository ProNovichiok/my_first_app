# Балтик Драйв — прокат автомобилей в Калининграде

Работающий демонстрационный проект: сайт, Node.js API, Telegram-бот, SQLite, два печатных экземпляра договора с актами, отдельное согласие и Excel-отчёт.

**Демонстрационные автомобили, цены и реквизиты вымышлены. Приём реальных документов по умолчанию заблокирован. Это не юридическое заключение и не готовый к коммерческому запуску договор.**

## Локальный запуск на Windows

1. Установите Node.js 24 LTS (https://nodejs.org/).
2. Откройте папку проекта и запустите `start.cmd`.
3. Откройте http://localhost:3000.
4. Кабинет: http://localhost:3000/admin.html. Ключ — `ADMIN_TOKEN` в локальном `.env`.
5. Нажмите «Создать демо-заявку»: пример договора и отчёт появятся в `private/`.

Через терминал:

```sh
npm ci
npm run setup
npm start
```

`npm test` — проверки бронирований, дат UTC+2, анкеты, шифрования, одноразовых ссылок, API, договоров, Excel и удаления данных.

## Что реализовано

- Каталог и фильтры, дата и время выдачи/возврата в **Europe/Kaliningrad, UTC+2**.
- Цена считается сервером, каждые начатые 24 часа — сутки. Залог отдельно.
- Проверка пересечений в транзакции SQLite. Временная заявка — 30 минут, рассмотрение анкеты — 24 часа.
- Оpaque Telegram start-параметр; привязка к одному Telegram-аккаунту. Паспорт и права в чате не запрашиваются.
- Отдельная одноразовая форма по ссылке из бота. Токен формы передаётся во фрагменте URL, затем удаляется из адресной строки и используется только в Authorization.
- ФИО, паспорт РФ, адрес регистрации, телефон и реквизиты водительского удостоверения РФ. Сканов, биометрии и иностранных документов в этой версии нет.
- Отдельное непредустановленное согласие; сохраняются текст, версия и время. Чекбокс не считается электронной подписью договора.
- AES-256-GCM для анкеты и Telegram chat ID в SQLite. Ключ хранится отдельно в `.env`.
- Кабинет владельца: список, ручная проверка, подтверждение, выдача, возврат, отмена, фактически полученная сумма аренды, скачивание файлов и удаление данных незаключённой заявки.
- Договор `.html`: **два одинаковых экземпляра, каждый с актом выдачи/возврата**. Откройте файл в браузере → Ctrl+P → PDF или принтер. Подписи — на бумаге после проверки оригиналов.
- `clients.xlsx`: листы «Заявки», «Статистика», «По месяцам». Имя, телефон, авто, даты, суммы и статусы; паспорта и номера прав в отчёт не включаются.
- Файлы автоматически обновляются после анкеты, действий владельца, запуска и каждый час; восстановление: `npm run export`.
- Данные отменённых/истёкших незаключённых заявок очищаются через 30 дней после завершения рассмотрения; соответствующие файлы также удаляются. Договоры по завершённой аренде автоматически не удаляются: нужен утверждённый законный срок хранения.
- Ограничение запросов, CSP, контроль Origin, закрытые служебные директории, журнал действий без содержимого документов.

## Где что находится

| Путь | Назначение |
| --- | --- |
| `public/` | Сайт и кабинет |
| `src/` | API, база, бот, генераторы |
| `config/company.json` | Реквизиты и условия проката |
| `config/cars.json` | Автопарк, тарифы, VIN, госномера, СТС и полисы |
| `data/rental.sqlite` | Локальная база, **не в GitHub** |
| `private/contracts/` | Договоры с актами, **не в GitHub** |
| `private/consents/` | Подтверждения согласия, **не в GitHub** |
| `private/reports/clients.xlsx` | Отчёт, **не в GitHub** |
| `.env` | Секреты, **не в GitHub** |
| `docs/LAUNCH.md` | Настройка настоящего сервиса |
| `docs/LEGAL.md` | Правовые требования и источники |

GitHub хранит и проверяет исходники. GitHub Pages не исполняет этот API и бота. GitHub Actions используется только для тестов с вымышленными данными.

Для сервиса нужен постоянно включённый компьютер в РФ с HTTPS или сервер в РФ. Docker Compose и пример Caddy включены. Домен, хостинг и уведомления регулятору **не настроены автоматически**.

## Telegram

Бот: https://t.me/CarArendaKLNGBot

`BOT_TOKEN` задаётся только локально в `.env`, `BOT_ENABLED=false` по умолчанию. Бот включается после настройки доступного клиентам HTTPS-адреса. Код не отключает существующий webhook и не удаляет очередь обновлений. Запускайте только один polling-процесс на токен.

Имя: **Балтик Драйв | Прокат авто Калининград**.

Описание: «Аренда автомобилей в Калининграде и области. Выберите авто и даты на сайте, продолжите оформление здесь и следите за статусом заявки. Паспорт и права заполняются в защищённой форме — не отправляйте документы в чат».

## Границы версии

Без онлайн-оплаты, электронной подписи, распознавания документов и автоматической проверки МВД. Проверка правомерности аренды, оригиналов, страхового покрытия, полномочий и подписание выполняются владельцем. Условия договора с пустыми полями заполняются до подписания. Автомобили представлены локальными оригинальными SVG-иллюстрациями, не фотографиями реального автопарка. Администратор один, с общим секретным ключом; для команды нужен учёт пользователей и ролей.

Ключ AES нельзя потерять: без него анкеты не восстановить. SQLite и секреты, документы и Excel требуют защиты доступа ОС, шифрования диска и резервных копий; шифрование поля базы не шифрует выгруженные договоры.

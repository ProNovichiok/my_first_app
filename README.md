# Балтик Драйв — Java

Сайт проката автомобилей в Калининграде, сервер, Telegram-бот, договоры и Excel. **Для запуска нужна только Java 21 или новее. Node.js и npm не используются.**

## Быстрый запуск

Готовая версия на компьютере: `F:\Нейронка\MyHTML\CarArendaKaliningrad`.

1. Запустить `start.cmd`.
2. Открыть http://localhost:3000.
3. Кабинет: http://localhost:3000/admin.html. Ключ — значение `ADMIN_TOKEN` в локальном `.env`.
4. Демонстрационная заявка уже сохранена. В кабинете можно скачать договор и Excel.

Через терминал:

```sh
java -jar baltic-drive.jar
```

Если .env ещё нет, приложение создаст его и сгенерирует ключ шифрования и ключ кабинета. Токен бота записывается в `BOT_TOKEN` вручную, только локально. Существующий .env не перезаписывается.

**Реквизиты, автомобили и цены вымышлены. Приём настоящих документов отключён. Для коммерческого запуска нужны реальные данные, сервер в РФ, HTTPS и утверждённые документы.**

## Сборка исходников

Нужны JDK 21+ и Apache Maven 3.9+:

```sh
mvn verify
java -jar target/baltic-drive.jar
```

На Windows можно использовать `build.cmd`: он проверит проект и скопирует jar в корень. Для запуска уже собранного jar Maven не нужен. В GitHub Actions выполняется `mvn verify` на Java 21; готовый jar доступен в артефакте `baltic-drive-java`.

## Реализовано

- Каталог, фильтры, дата и время выдачи/возврата в **Europe/Kaliningrad, UTC+2**.
- Серверный расчёт каждых начатых 24 часов; залог отдельно.
- Проверка занятости и резервирование в транзакции SQLite, включая одновременные запросы. Временная заявка — 30 минут, проверка анкеты — до 24 часов.
- Telegram start-параметр содержит случайный токен. Бот связывает заявку с одним аккаунтом и выдаёт одноразовую ссылку на форму. `/status` — последние пять статусов.
- Паспорт РФ и водительское удостоверение РФ заполняются через форму, не в чате. Фото и биометрия не собираются. Иностранные документы в этой версии не поддерживаются.
- Отдельный checkbox согласия, сохранение текста, версии и времени. Он не заменяет подпись договора.
- AES-256-GCM для анкеты и Telegram chat ID, ключ в .env; совместимость с ранее созданной базой.
- Кабинет: проверка, подтверждение, выдача, возврат, отмена, фактически полученная сумма аренды, скачивание и удаление личных данных незаключённой заявки.
- HTML-договор: **два экземпляра, каждый с актом выдачи/возврата**. Печать: Ctrl+P → принтер или PDF. Подписание отдельно после проверки оригиналов.
- Настоящий `.xlsx` через Apache POI: «Заявки», «Статистика», «По месяцам». ФИО, телефон, авто, даты, суммы и статусы; реквизиты паспорта и прав в отчёт не включены.
- Отчёт обновляется после изменений, при запуске и каждый час. Восстановление файлов: `java -jar baltic-drive.jar --export`.
- Анкеты отменённых/истёкших заявок и соответствующие локальные файлы удаляются через 30 дней после завершения рассмотрения. Срок хранения подписанных договоров определяется владельцем отдельно.
- Закрытые служебные файлы, ограничение запросов, CSP, проверка Origin и журнал без содержимого документов.

## Технологии

Java 21+, встроенный JDK HTTP Server и виртуальные потоки, SQLite JDBC, Jackson, Apache POI, JUnit. Один jar включает сервер, бот, генераторы и фронтенд. В браузере работают обычные HTML/CSS/JavaScript; серверного JavaScript нет.

## Файлы

| Путь | Назначение |
| --- | --- |
| `src/main/java/ru/balticdrive/` | Java-код |
| `src/main/resources/templates/` | Договор, согласие и политика |
| `src/test/java/` | Автоматические проверки |

| `data/rental.sqlite` | Клиентская база, не в GitHub |
| `private/contracts/` | Договоры, не в GitHub |

| `private/reports/clients.xlsx` | Статистика, не в GitHub |

Конфигурация, .env, база и файлы располагаются рядом с jar. Приложение запускают из этой папки. GitHub хранит код и собирает jar; GitHub Pages не запускает Java-сервер. Для работы клиентов нужен постоянно включённый компьютер/сервер в РФ с HTTPS.

https://t.me/CarArendaKLNGBot

Имя: **Балтик Драйв | Прокат авто Калининград**.

Описание: «Аренда автомобилей в Калининграде и области. Выберите авто и даты на сайте, продолжите оформление здесь и следите за статусом заявки. Паспорт и права заполняются в защищённой форме — не отправляйте документы в чат».

`BOT_ENABLED=false` по умолчанию. Для включения нужны действующий локальный BOT_TOKEN и доступный клиентам PUBLIC_URL с HTTPS. Запуск проверяет username и существующий webhook, не отключает чужую интеграцию и не очищает очередь. Нужен один polling-процесс на токен. Документы и Excel в Telegram не отправляются.

## Переход с предыдущей версии

Существующие .env, ключ AES, SQLite и локальные документы сохранены. Формат шифрования и структура записей совместимы. Старые Node.js-исходники и зависимости перемещены в отдельную резервную папку рядом с проектом. Они не используются новой версией и не загружены в текущую ветку GitHub.

## Перед рабочим запуском

См. `docs/LAUNCH.md` и `docs/LEGAL.md`. Нужны реальные реквизиты и машины, проверка договора и правовых оснований обработки, локализация, необходимые уведомления регулятору, оценка Telegram, защита доступа ОС и резервных копий. LEGAL_READY — отметка владельца, не юридическая экспертиза.

Без онлайн-оплаты, электронной подписи, распознавания и проверки документов МВД. Excel не заменяет кассовую или бухгалтерскую систему. Договоры выгружаются в читаемом виде для печати: защитите папку private и носитель. Потеря DATA_KEY делает анкеты невосстановимыми.

## Сайт для показа учителю — GitHub Pages

Папка `pages/` содержит отдельную учебную публикацию. На ней работают каталог, расчёт цены, локальные демо-заявки и демо-кабинет. Есть проверенные вымышленные образцы договора и Excel. Настоящая анкета, Java-сервер и бот на GitHub Pages не исполняются.

Публикация запускается workflow `.github/workflows/pages.yml`. В Settings → Pages выберите Source: GitHub Actions. Для приватного репозитория нужен тариф с поддержкой Pages; на GitHub Free репозиторий для Pages должен быть публичным. Приватность автоматически не меняется.

Адрес после успешного включения и развёртывания: https://pronovichiok.github.io/my_first_app/ . До завершения развёртывания этот адрес может возвращать 404.

Никакие .env, ключи, базы или клиентские документы в публикацию не входят. Учебные заявки хранятся только в localStorage браузера посетителя; они не синхронизируются и не создают реальную бронь. `demo-contract.html` и `demo-clients.xlsx` — фиксированные вымышленные образцы, а не выгрузка данных посетителей.

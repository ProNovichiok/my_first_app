На публичных страницах нет ссылок на админ-панель. Это удобство интерфейса, а не защита доступа. Рабочая панель и API защищены ADMIN_TOKEN. На Pages показаны только локальные учебные заявки, без настоящего пароля владельца и клиентских документов.

## Изменения

- Графитовый фон, тёплые янтарные и бирюзовые акценты, адаптивное мобильное меню.
- 8 автомобилей с отдельными реалистичными изображениями, созданными с ИИ.
- Вращение карточки на 360° мышью, касанием и стрелками клавиатуры; кнопки поворота и сброса. Обратная сторона содержит характеристики. Это вращение самой карточки, не круговая фотосъёмка машины.
- Дополнительная страница маршрутов.
- Небольшие фоновые CSS-анимации. Они останавливаются в неактивной вкладке; при prefers-reduced-motion отключены.
- Поиск, фильтры, статусы, оплаты, экспорт Excel и раздел автопарка в админ-панели.
- Node.js/npm не используются в приложении или в пользовательской сборке. Java 21+ для сервера; Python только для подготовки статической версии и диагностики.
- Shared frontend: public/ для Java; scripts/build-pages.py создаёт pages/ для GitHub Pages.
- Защита от двух процессов, использующих одну базу.

## Telegram

В .env используются разные адреса:
PUBLIC_URL=http://localhost:3000
BOT_PUBLIC_URL=https://pronovichiok.github.io/my_first_app/
BOT_ENABLED=true

PUBLIC_URL — адрес полного Java-сайта и проверка Origin. BOT_PUBLIC_URL — публичный каталог для кнопок Telegram. Для настоящего сервиса оба адреса должны вести на рабочий HTTPS-сервер.

GitHub Pages передаёт только выбранную модель и время через учебный параметр d1. Бот повторно проверяет параметры и цену, сохраняет заявку локально, для образца договора использует только вымышленные реквизиты. В рабочем режиме учебные d1-ссылки отвергаются; действует случайный токен с защищённой формой.

Компьютер должен быть включён и подключён к интернету. Обычный GitHub Pages бот не исполняет. Для круглосуточной работы перенесите Java-приложение на сервер. Токен в .env и никогда не публикуется.

Проверка соединения: check-bot.cmd или java -jar baltic-drive.jar --check-bot.
Запуск: start.cmd. Приложение работает, пока запущен Java-процесс. Для постоянного запуска на сервере есть deploy/baltic-drive.service. Для сборки: mvn verify.
